## Repositorio Aplicaciones Web II
### Proyecto HogarLimpio
Aplicación web para gestión de servicios de limpieza del hogar.
REST API desarrollada con Python, Django.
Para Gestionar Clientes, Servicios, Solicitudes.

## Tecnologías
- Python
- MVC
- DAO/ORM
- Django
- GIT

## Funcionalidades
- Registro de clientes
- Gestión de servicios
- Consulta de información
- Actualización y eliminación de registros

## Arquitectura
Controller
    ↓
Service
    ↓
Repository
    ↓
Database
